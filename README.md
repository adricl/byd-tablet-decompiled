# byd-tablet-decompiled: Decompiled all BYD apps from the on car tablet to allow for Android Dev 

# What?: 
* List of all the BYD apps from the Car Tablet and what each app does based on the decompilation
* Android Stubs for all the BYD Framework to allow for development of apps
* List of all the signals that the BYD Car Server DiCarServer.apk (com.byd.car.server)

# Why?
I have been wanting to build an app for the BYD in car tablet but the device has security blocking getting any data from car. 
There is also no SDK for android so I have built one.
